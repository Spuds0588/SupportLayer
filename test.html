Manual flow

  1. Load the widget, then trigger SupportLayer.requestHelp() from the floating button (or your own button) and submit the form.
  2. Open the live_session_url from the payload — it is this very page plus ?sl_role=agent&peer=…, so the widget boots into the agent view instead of the request button. Two browser windows are required for the real PeerJS path; data-demo uses the loopback bus inside one page.
  3. For the real WebRTC path, turn data-demo off and serve over http or https — capture needs a secure context and a real click.
